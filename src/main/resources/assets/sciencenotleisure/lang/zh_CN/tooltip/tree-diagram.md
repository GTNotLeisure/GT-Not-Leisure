每份配方以 64 个电路为基准，材料来自纳米电路工厂、电路装配线和电路组装机。
消耗的物品与流体按九折向下取整；元件先打折，再打包，零头保留为散件。
先在解锁面板提交对应主机，才能制作该系列。可分批提交，进度会保存。
同系列只收最高级主机：晶体系列交付 52,488 个 UV 晶体主机后，IV～UV 一起解锁。
独立电路按自身等级计数：ULV 需要 524,288 个，每升一级在上一级数量上减少 25%，向下取整。
解锁后还要满足 NEI 中的蜂群等级；蜂群为 T1～T10。
四个蜂群槽中，一个是主槽，三个是辅助槽。主槽决定效率、制作等级、损耗和增产。
辅助槽只增加并行，按能力排序依次贡献 50%、25%、12.5%；等级不够或本批用不到的辅助槽不参与。
正在参与的蜂群在整批出料前不能替换，也不会被消耗。
维护液分三档：四级净化水、六级净化水、八级净化水。
T1～T3 消耗第一档；T4～T6 同时消耗前两档；T7～T10 同时消耗全部三档，等级越高用量越大。
主蜂群和参与的辅助蜂群都要付维护费；加速时用量增加。运行面板会列出每种液体的实时用量。
白值蜂群在维护齐全时没有损耗。赌狗蜂群仍有风险：低、中、高三个阶段最低为 22%、14%、6%。
一次损耗只让对应并行减产 25%；普通增产事件增加 30%。两种事件可同时发生。
高档维护液不能消除低阶赌狗蜂群的风险；多余算力也不能抵消损耗。
可接入有线或无线算力输入仓。不同配方、并行和基础加速需要的算力不同。
算力会在运行中更新：只给一半算力时速度为四分之一，EU/t 为 1.75 倍。
达到需求后继续增加算力可以加速；超过两倍需求后，继续加算力的收益逐渐降低。
没有算力仍可极低效运行：速度降到六十四分之一，EU/t 增至四倍。
缺电、缺维护液、结构不完整或输出堵塞时会暂停，保留原料投入、进度和本批产出结果。
待机和暂停不消耗新的维护液；补齐条件后继续。拆下控制器会保留解锁进度和槽内物品。
更多蜂群的参数仍会继续平衡；显示“尚未登记”的蜂群暂时不能参与制作。
